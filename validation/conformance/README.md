# Conformance Validation

**CR-BP-03.**

This directory is a forward-looking alias for the catalog's
conformance validation gates. The canonical implementation
lives under `scripts/` (e.g. `scripts/check_ecf_conformance.py`,
`scripts/check_process_specialization.py`,
`scripts/check_process_context.py`,
`scripts/check_process_identity.py`).

In future CRs (CR-BP-03A or later), this directory may be
extended with subdirectories for additional validation concerns
(e.g. `validation/migration/` for legacy-entry migration
checks).
